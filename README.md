# ChatGPT

ChatGPT is a smart, AI-powered chatbot that provides human-like conversations, answers questions, and offers interactive discussions across various topics. It features an intuitive user interface with light/dark mode options, recent chat history, and real-time AI responses.

## Features

- **Natural Conversations**: Engages in context-aware, human-like interactions.
- **Customizable Themes**: Toggle between light and dark mode for better user experience.
- **Recent Chat History**: Keeps track of recent chats for easy reference.
- **Real-Time Responses**: Instant answers powered by AI technology.
- **Responsive Design**: Works seamlessly across desktop, tablet, and mobile devices.
- **Multi-Domain Knowledge**: Can provide answers and information on various topics.
- **Accessibility**: Built with accessibility features like keyboard navigation and readable styles.

## Technologies Used

- **Frontend**: React.js
- **Backend**: Google Gemini API (Generative Language Model)
- **Styling**: Tailwind CSS
- **State Management**: React's `useState`, `useEffect`
- **API Requests**: Axios
